== はじめに

ここまでの手順で、Rulebookの中身を確認しましたが、それをどのように起動するかはまだ見ていませんでした。**Rulebook Activation**は、イベント駆動型Ansibleの「常時リッスンする」部分です。これは、プロジェクト（Rulebookを含む）とDecision Environmentを組み合わせて、常に実行され、新しいイベントの処理を待機するリスナーを作成します。

イベント駆動型Ansibleは、`Rulebook Activation`が障害で停止した場合の再起動を管理し、`**Rule Audit**`画面には、Rulebookの条件に一致するイベントが受信されるたびに記録が表示されます。

== タスク: Rulebook Activationの作成

このタスクでは、`Rulebook Activation`を作成し、有効化します。

. **Rulebook Activationsページに移動します。** `AAP`タブで、左側のナビゲーションメニューから **Automation Decisions** → **Rulebook Activations** を選択します。
. 青い**Create rulebook activation**ボタンをクリックして、新しい`Rulebook Activation`を作成します。
. **アクティベーションの詳細を入力します。** 以下の値でフォームに入力してください。
+
[cols="1,2,2a"]
|===
| キー | 値 | 備考

| *Name*
| `Alertmanager events`
|

| *Description*
| `Catch alerts coming from alertmanager`
|

| *Organization*
| `Default`
|

| *Project*
| `My EDA project`
|

| *Rulebook*
| `alertmanager.yml`
|

| *Credential*
| `AAP`
| この認証情報は、Automation Controllerでジョブテンプレートを実行するために使用されます。

| *Decision environment*
| `Workshop Decision Environment`
|

| *Restart policy*
| `On failure`
|

| *Log level*
| `Debug`
|

| *Rulebook activation enabled?*
| ☑
| これが有効になっていることを確認してください。
|===
+
NOTE: 製品ドキュメントについては、こちらを参照してください: link:https://docs.redhat.com/en/documentation/red_hat_ansible_automation_platform/2.5/html/using_automation_decisions/eda-rulebook-activations[Using automation decisions: Chapter 8. Rulebook activations].

. フォームの下部にある**Create rulebook activation**ボタンをクリックして、アクティベーションを保存します。
+
image::Nov-12-2024_at_13.56.18-image.png[入力が完了したRulebook Activationフォーム, opts="border"]

. **アクティベーションのステータスを確認します。** 新しい`Rulebook Activation`の詳細ページに移動します。*Activation status*は「Pending」または「Starting」と表示されるかもしれませんが、すぐに**Running**に移行するはずです。
. **アクティベーションの履歴を確認します。** 上部にある**History**タブを選択します。この`Rulebook Activation`が開始または再起動されるたびに、新しいIDが割り当てられ、このページに新しいエントリが追加されます。これは、各アクティベーションがコンテナ内で実行される新しい`ansible-rulebook`プロセスであるためです。
+
image::Oct-17-2024_at_13.46.34-image.png[実行中のRulebook ActivationのHistoryタブ, opts="border"]

. **デバッグ出力を表示します。** 実行中のアクティベーションのリンク（例：「1 - Alertmanager events」）をクリックすると、実行中のRulebookのライブデバッグ出力を確認できます。

この時点で、AlertmanagerからのイベントをアクティブにリッスンしているRulebookができました。
